SISTEM VAULT DOKUMEN & ID (OFFLINE PWA)
=======================================

Kandungan Pakej:
1. index.html   - Antaramuka penuh, enjin enkripsi AES-256 GCM, & storan IndexedDB.
2. manifest.json - Konfigurasi Progressive Web App (PWA) untuk instalasi telefon.
3. sw.js        - Service Worker untuk membolehkan sistem berfungsi 100% tanpa internet.

CARA PENGGUNAAN:
----------------
Pilihan A (Komputer):
- Ekstrak fail zip ini dan klik 2 kali pada fail `index.html` untuk buka di Chrome / Edge / Brave.

Pilihan B (Telefon - PWA Install):
1. Muat naik (upload) fail `index.html`, `manifest.json`, dan `sw.js` ke GitHub Pages percuma atau hosting anda.
2. Buka pautan URL web tersebut di Google Chrome (Android) atau Safari (iOS).
3. Tekan menu pelayar (3 titik di Chrome / butang Share di Safari) dan pilih "Add to Home screen" / "Install App".
4. Buka aplikasi tersebut dari skrin utama telefon walaupun dalam mod kapal terbang (Airplane Mode / Offline).
